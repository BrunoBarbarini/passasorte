# tests/

Cross-app/package suites that don't belong to a single workspace: selected
end-to-end flows (CLAUDE.md #39 - participation, game, result and
conditional payment flows) and any future load tests (CLAUDE.md #37
NFR references, #61).

Unit/domain and integration tests for a given package live next to their
source inside that package (e.g. `packages/config/src/__tests__/`), not
here.
